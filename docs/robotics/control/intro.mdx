# Introduction

Control theory is a branch of engineering and mathematics that deals 
with the behavior of dynamical systems. The objective of control theory
is to develop models and algorithms that can influence the behavior of 
these systems to achieve desired outcomes.

We will cover the following topics in this section:
- PID Control
- Kalman Filters(Extended Kalman Filter, Unscented Kalman Filter)
