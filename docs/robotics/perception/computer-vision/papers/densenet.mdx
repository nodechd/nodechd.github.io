# DenseNet

DenseNet (Densely Connected Convolutional Networks) is a deep learning
architecture that connects each layer to every other layer in a 
feed-forward fashion. This design allows for improved information
flow and gradient propagation throughout the network, leading to
better performance and efficiency. It has implicit deep 
supervision, which helps in training very deep networks.

Link: [Link to the original paper](https://arxiv.org/abs/1608.06993)
